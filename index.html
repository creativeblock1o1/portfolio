1) Tiesverse Foundation Website↗

A collaborative website project for Tiesverse Foundation, developed alongside my teammates. I contributed to the website’s visual direction and interface design, refining the user experience through iterative improvements and helping shape how the organisation presents itself digitally.

Visit Website ↗
2) Tiesverse Admin Panel↗

Alongside the main website, I collaborated with my teammates on the design of Tiesverse Foundation’s internal administrative panel and Ties Mail, an email-like communication portal. The admin panel is designed to simplify website content management and organisational updates without requiring changes to the underlying code, while Ties Mail provides a dedicated platform for internal communication. Due to the sensitive nature of the information handled by these systems, only selected interface screens are showcased here.
